# 🎀 StudyBunny 🐰💗

A dreamy baby-pink study companion that makes focusing a little sweeter!

## Features
- ⏱️ 25-minute focus timer and 5-minute break timer
- 🐰 Animated bunny that grows every three completed focus sessions
- 🥕 Earn two carrots per completed focus session
- 🌸 Track completed sessions and total focus minutes
- 💾 Progress automatically saved in your browser using localStorage
- 🎀 Responsive pastel-pink design

## Run
Open `index.html` in a browser. No installation or API key required.

## Publish with GitHub Pages
Go to **Settings → Pages → Build and deployment → Deploy from a branch**, select **main** and **/(root)**, then save.

> Keep the study tab open while the timer runs. Saved progress is local to each browser/device.

Made with HTML, CSS, and vanilla JavaScript. 💗
